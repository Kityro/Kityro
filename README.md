💳 Sistema de Gestão de Crédito

Meu primeiro projeto full stack: portal que consulta dados cadastrais por CPF e mostra nome, data de nascimento e situação de restrição do cliente. Aqui usei IA como apoio para acelerar, com foco em entender lógica, estrutura e boas práticas.

Back-end: API REST com FastAPI, validação com Pydantic e persistência com SQLAlchemy
Banco de dados: SQLite local, com fallback automático para PostgreSQL
Integração: consumo de API externa (CPFhub.io) para dados reais
Front-end: login, dashboard, histórico de consultas e anotações por cliente
Boas práticas: código em camadas, variáveis de ambiente e script de deploy em VPS
